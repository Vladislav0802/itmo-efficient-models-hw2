# Аналитический ноутбук

Основная инструкция перенесена в README.md. Единственный ноутбук: notebooks/01_analysis.ipynb.
Он читает JSON/CSV из results/, строит 8 графиков и таблицы без GPU, данных и весов.
Графики 01–06 относятся к сохранённой машинной оценке; 07–08 добавляют контрольные результаты, восстановленные из консоли. Источники и ограничения описаны в docs/report.md и results/extra/PROVENANCE.md.
